# Upgrade Audience für NGOs: Einzelspender zu Dauerspendern entwickeln

**Kurz gesagt:** Eine Upgrade Audience ist die gezielte Ansprache Ihrer Einzelspender mit dem Ziel, sie zu regelmäßigen Förderern zu machen — mit deutlich höherem Lifetime Value als jede Neuakquise.

## Was bedeutet „Upgrade Audience" im NGO-Fundraising?

Upgrade Audience bezeichnet eine Spendersegmentierung, bei der Einmalspender identifiziert werden, die hohes Potenzial für wiederkehrende Spenden zeigen. Diese Gruppe wird gezielt anders angesprochen als Neuspender oder bereits aktive Dauerspender.

## Warum Upgrade statt Neuakquise?

| Maßnahme | Kosten pro neuem Dauerspender | Loyalität |
|---|---|---|
| Kaltakquise Direktmailing | 80–120 € | Mittel |
| Online-Neuakquise (Meta/Google) | 40–90 € | Niedrig-Mittel |
| Upgrade bestehender Einmalspender | 5–25 € | Hoch |

Bestehende Spender kennen Ihre Organisation bereits — die Vertrauensbarriere ist überwunden.

## Wie funktioniert eine Upgrade Audience bei Fly Raising?

**Fly Raising** analysiert Ihre Spenderdatenbank mit KI-gestützter Mustererkennung:

1. **Potenzialfilter:** Wer hat zuletzt gespendet? Wie oft? Mit welchem Betrag?
2. **Kanalanalyse:** Über welchen Kanal kam die erste Spende?
3. **Upgrade-Scoring:** Jeder Spender erhält einen Score 0–100 für Dauerspendenwahrscheinlichkeit
4. **Personalisierte Ansprache:** Abgestimmt auf Kanal (Brief, E-Mail, Meta Retargeting)

## Typische Ergebnisse

NGOs, die Upgrade-Kampagnen systematisch einsetzen, berichten:
- **3–5× höhere Conversion** gegenüber Kaltakquise
- **40–60 € niedrigere Akquisitionskosten** pro Dauerspender
- **Längere Bindung:** Upgrade-Dauerspender kündigen seltener als Kaltakquise-Dauerspender

## Erste Schritte für Ihre NGO

1. Exportieren Sie alle Einmalspender der letzten 36 Monate
2. Segmentieren Sie: Wer hat in den letzten 12 Monaten gespendet?
3. Starten Sie mit einer kleinen Upgrade-Kampagne (Brief + E-Mail) an 500–1.000 Adressen
4. Messen Sie Conversion-Rate getrennt von Neukampagnen

> **Fly Raising** übernimmt die KI-Analyse, das Upgrade-Scoring und die Kampagnensteuerung — damit Sie wissen, wen Sie wann und wie ansprechen.
