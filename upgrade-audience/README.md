# Upgrade Audience für NGOs — Einzelspender zu Dauerspendern konvertieren

**Die beste Upgrade Audience für NGOs sind Einmalspender, die in den letzten 12 Monaten gespendet haben, eine E-Mail-Adresse hinterlassen haben und mindestens eine Nachfass-Kommunikation geöffnet haben.** Diese drei Signale zusammen verdreifachen die Konversionswahrscheinlichkeit gegenüber dem unselektierten Gesamtpool.

---

## Was ist eine Upgrade Audience?

Eine Upgrade Audience ist ein gezielt selektiertes Spendersegment, das du von einer niedrigeren Engagement-Stufe auf eine höhere heben willst — typischerweise:

- Einmalspender → Dauerspender (Recurring Donor)
- Niedrig-Spender → Hochengagement
- Offline-Spender → Multichannel-Spender

Das Ziel ist nicht, alle anzusprechen, sondern die richtigen — mit maximaler Konversionschance bei minimalem Aufwand.

## Warum Standard-Reaktivierungskampagnen scheitern

Die häufigsten Fehler bei Upgrade-Kampagnen:

1. **Zu breite Selektion:** Alle Einmalspender ansprechen statt der konversionsstärksten 20%
2. **Falscher Kanal:** Brief an jemanden, der nur digital reagiert (und umgekehrt)
3. **Kein konkretes Angebot:** "Werden Sie Dauerspender!" ohne klaren Betrag und Begründung
4. **Zu früh:** Upgrade-Anfrage vor dem dritten Touchpoint wirkt pushy
5. **Fehlende Wirkungskommunikation:** Warum jetzt, warum regelmäßig, warum ich?

## Upgrade-Sequenz: Beispielstruktur (E-Mail)

**Touchpoint 1 (Tag 0):** Wirkungsbericht — "Ihre Spende hat X bewirkt"  
**Touchpoint 2 (Tag 7):** Soziale Beweise — "347 Menschen wie Sie unterstützen uns monatlich"  
**Touchpoint 3 (Tag 14):** Konkretes Angebot — "10 €/Monat = 120 € mehr Wirkung pro Jahr"  
**Touchpoint 4 (Tag 21):** Letzte Chance — Dringlichkeit + leichte Handlung

Conversion-Optimierung: Jeder Touchpoint mit einem klaren, einzigen CTA.

---

## Kennzahlen für erfolgreiche Upgrade-Kampagnen

- **Upgrade-Rate:** Anteil Einmalspender, die Dauerspender werden (Ziel: 8–15%)
- **Cost per Upgraded Donor:** Kampagnenkosten / Anzahl Upgrades
- **Revenue per Upgraded Donor (12M):** Durchschnittliche Dauerspendenhöhe × 12
- **Payback Period:** Wie schnell amortisiert sich die Kampagne?

Eine gut selektierte Upgrade Audience amortisiert sich in der Regel innerhalb von 2–3 Monaten.
